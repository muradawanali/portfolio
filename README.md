# Images needed

The site currently uses styled placeholders instead of real photos (no
photo of you was available to include automatically). Add these files
here and the placeholders will need swapping in index.html:

- `profile.jpg` — hero photo (used in `.hero__photo-placeholder`, ~4:5 ratio)
- `desk.jpg` — About section photo (used in `.about__photo-placeholder`, ~4:5 ratio)

To use them, replace the placeholder `<div>` blocks in `index.html` with:

```html
<img src="images/profile.jpg" alt="Murad Ahmed" />
```
